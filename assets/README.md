# Illustrations

Drop these files here. The app shows a designed gradient until each one exists, so any of them can be added later.

| File | Where it appears | Size |
|---|---|---|
| `match-hero.webp` | Home: the "Next match" card header | 1600×900 (16:9) |
| `welcome.webp` | "Who are you?" name picker, top of the sheet | 1600×800 (2:1) |
| `potm-badge.webp` | Player of the match: round badge | 512×512 (1:1), subject centred |
| `favicon-32.png` | Browser tab icon (pixel-art floorball) 

Export as WebP at about 80% quality (aim for under 250 KB each). Keep the important part of each image away from the bottom third, because text and a dark fade sit there.
